Firmo – تطبيق ويب يعمل بدون إنترنت (PWA)

الملفات (ارفعها كلها بنفس الهيكل في نفس المجلد):
  index.html            التطبيق كامل
  manifest.webmanifest  بيانات التثبيت
  sw.js                 يخزّن التطبيق للعمل بدون إنترنت
  icons/                الأيقونات

التشغيل والتثبيت:
1) ارفع المجلد على أي استضافة HTTPS مجانية (GitHub Pages / Netlify / Cloudflare Pages / Vercel).
   للتجربة على الجهاز: افتح الطرفية داخل المجلد ونفّذ:  python3 -m http.server 8000
   ثم افتح http://localhost:8000
2) افتح الرابط مرة واحدة وأنت متصل، لتُحفظ الملفات تلقائيًا.
3) التثبيت:
   - Windows / Mac / Linux / ChromeOS (Chrome أو Edge): أيقونة التثبيت في شريط العنوان، أو زر 📲 داخل التطبيق.
   - Android: القائمة ⋮ ← تثبيت التطبيق.
   - iPhone / iPad (Safari): مشاركة ← إضافة إلى الشاشة الرئيسية.
   - Mac (Safari): ملف ← إضافة إلى Dock.
4) بعد أول فتح يعمل التطبيق بدون إنترنت بالكامل.

تحديث النسخة: غيّر VERSION في sw.js واسم الكاش 'firmo-v6-...' داخل index.html بنفس القيمة، ثم ارفع الملفات.
ملاحظة: ربط OneDrive يحتاج رابط HTTPS ثابت ليُسجَّل كـ Redirect URI.
